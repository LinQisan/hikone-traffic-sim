場面

作り方

  1. 場面を選ぶ：一覧から開く、または「＋ 新規」。ひな形は別の id で保存されます。
  2. 出発・ゴール・トリガーを地図上でドラッグ（□ 大きさ ・ ○ 向き）。
  3. ✎ 車を描く：クリックで点、Enter で完了。右の「車」で速さと事故車を指定。
  4. 下の ▶ で動きを確かめ、チェックが OK なら ▶ ブラウザで試す → 保存。
マウスとキーの操作
  • ドラッグ：移動 ・ 空白をドラッグ：地図を動かす ・ ホイール：拡大縮小
  • ルート上をダブルクリック：点を追加 ・ 点を右クリック：削除
  • V 選択 ・ C 車を描く ・ F 全体表示
  • Space 再生 ・ Delete 削除 ・ Esc 選択解除
  • Ctrl+S 保存 ・ Ctrl+Z 元に戻す
