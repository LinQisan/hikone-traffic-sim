# Hikone Traffic Simulator（彦根交通安全シミュレーター）

[VRLearn](https://github.com/LinQisan/VRLearn)（Meta Quest 2 向けの歩行者向け交通安全 VR 体験）のブラウザ版です。three.js（r186）を使い、ビルド手順も外部パッケージも不要です。彦根・京橋の街、10 の組み込み場面と JSON のカスタム場面を、パソコンのブラウザ（マウス＋キーボード）とスマートフォン・タブレットのブラウザ（タッチ操作）で体験できます。VR（WebXR）には対応しません。VR で体験する場合は Unity 版を使います。

## 動かし方

```bash
node serve.mjs            # http://127.0.0.1:8770/
```

- **パソコン**：場面と身長を選んで「開始」。画面をクリックするとマウスで視点が動きます（Esc で解除）。WASD・矢印キーで移動、R でやり直し。
- **スマートフォン・タブレット**：同じ URL を開きます（同じ LAN の端末からは `node serve.mjs --host 0.0.0.0` で起動し、パソコンの IP アドレスで開く）。左下のスティックで移動、画面のほかの場所をドラッグして見回します。横向きがおすすめです。HUD の「やり直し」で最初から。リプレイと結果は画面のボタンで進みます。
- **接触**：車と接触すると一瞬赤く光り、視点が体と一緒に倒れます（車の進行方向へ投げ出され、体の側面を下にして地面に横たわる）。約 1.6 秒後にリプレイが始まります。記録される位置は接触した場所のままです。
- **リプレイの倒れ方**（`src/crash.js`）：接触した場所と車の速さで変わります。**車の正面**：ボンネットに一瞬もたれてから、車の進む方向へ飛ばされ（速いほど遠く・高く）、着地して滑る。**車の角**：外側へはじかれて回転する。**車の側面**：横へ押されて回転し、飛ばない。**止まった車にぶつかった**：来た方向へ尻もちをつくように倒れる。飛んでいる間は手足が振られ、着地後は力が抜けます。自転車では人と自転車が離れ、自転車は横倒しになります。事故の再現ではなく、教育用の表現です。
- **リプレイの視点**：「俯瞰 / Overview」（上から車の進路を横切る向き）と「運転者 / Driver」（V キーでも切替）。運転者の視点は事故車の運転席（右ハンドルなので車の中心から右へ 0.37 m、目の高さは車高の 78 %）から進行方向を見ます。車体の代わりにダッシュボード・ハンドル・A ピラー・屋根の縁・車の色のボンネットを描き、体験者が前に現れてから接触するまでを運転者の目で見られます。選んだ視点は次のリプレイでも続きます。
- **画風**：印象派向けに作り直したモデルを使います。町家・蔵のゆるく曲がる屋根、凹凸のある漆喰、簡略化した建具、枝の間に空が見える樹冠、立体の筆触と頂点カラーがモデルそのものに入っています。道路・石垣は冷暖色の絵の具と薄い筆触メッシュで描きます。街灯・信号機・5 種類の車は、抽象絵画の大きな色面を元に新しく造形しています。街灯の底・信号機の背面・車体とタイヤは閉じた立体です。全画面フィルターは使わず、パソコンと VR が同じモデルを描画します。P キーは細い筆の毛と光の色の仕上げを切り替えます（モデルの形・色・立体の筆触は残ります）。道路の高さ、車の大きさ、配置、当たり判定は元の場面に合わせています。
- **リプレイの体験者**：小熊（緑のスカーフ）で表示します。丸い頭・口元・鼻・目のハイライト・耳の内側・腮紅・お腹・尻尾があり、腕と脚は「上・下・手先（足先）」の関節で動きます。画像テクスチャはなく、頂点カラーの 1 材質です。メニューの**身長**で背丈（耳の先が身長）と体験中の目の高さが、**体重**で体つき（BMI から胴と手足の太さ）が変わります。
- **自転車**：場面 07・08・10 と `playerMode: bicycle` のカスタム場面では、体験者の視点からも自分の手と脚が見えます。手はハンドルのグリップを握り、脚はペダルに合わせてこぎます（胴と頭は視点の邪魔になるので隠す）。目の高さはサドルに座った小熊の目の位置です。リプレイでは小熊がサドルに座り、手でグリップを握り、足でペダルを踏みます。車輪とクランクは移動距離に同期します。
- **自転車の操作**：自転車は自分の向きを持ち、視線とは別です。W・↑（スマートフォンはスティック上）でこぎ出し、S・↓ でブレーキ、止まってからさらに押すと向きを変えずにゆっくり後ろへ押し戻します。A・D（スティック左右）でハンドルを切り、走りながら弧を描いて曲がります（Uターンも弧を描く。止まっている時はゆっくり向きを変えられる）。見回しても自転車は向きを変えず、肩越しに約 150° まで振り返れます。自転車が曲がると視線も一緒に回ります。リプレイの小熊は、振り返る角度に応じて上半身をひねり（約 26° まで）、残りを首で回し、手はハンドルを握ったままです。
- **描画性能**：街は 1 つの共有マテリアル（顔料ごとの色は頂点の顔料番号と小さな顔料表テクスチャで指定）で描き、資産ごと・詳細レベルごとに 1 回の InstancedMesh 描画にまとめます（以前の顔料・物体ごとのマルチドロー約 3,900 回 → 約 120 回）。見えている配置と遠景 LOD は毎フレーム CPU で選び、手前から順に並べます。影の再描画は影の範囲内の物体だけを描きます。大きな道路・地面・城山の地形は粗い区画に分けます。パソコンではフレーム時間に合わせて解像度を自動で下げ・戻し（最低 50%、FPS 表示の % がその値）、`?quality=high` で DPR 2 上限・固定解像度に戻せます。デュアル GPU のノートでは高性能 GPU を要求します。計測方法と結果は [docs/performance.md](docs/performance.md) にあります。
- 流れは Unity 版と同じです：場面を歩く（自転車の場面も同じ速さ）→ 車と接触すると赤い光と停止 → 三人称のリプレイ（接触の前 8 秒〜後 1.6 秒、接触前後はスロー、最後で止まって「結果へ進む」を待つ）→ 結果（Unity と同じ評価と文章）。ゴールに着くと成功の結果（左右の確認）。

リプレイは終了しても自動で結果へ進みません。「結果へ進む / Next」（再生中は「スキップ / Skip」）をクリック（タップ）して進みます。背景で Enter・空白キーを押しても進みません。

## データの更新

`data/` は Unity プロジェクトから作ります（このリポジトリは VRLearn の隣（`../VRLearn`）に置く前提。別の場所なら `VRLEARN_ROOT` / `VRLEARN_WEB` を指定）。

1. Unity：`Tools/VRLearn/Web/Export Scene For Web` → `data/scene.json`（Unity のマテリアル、光と霧、信号の位置、黒い壁、場面ごとの駐車車両とトラック）と `data/signals.json`（信号機のメッシュをシーンにあるとおりの位置で。同じ形のメッシュは 1 つにまとめる）。
2. Blender：`Blender -b --factory-startup --python tools/export_models.py` → `data/models/*.glb`（VRLearn の生成スクリプトそのもので全モデルを作り、glb で書き出し。ブラウザ用のセダンを追加）。
3. `node tools/sync.mjs` → 配置（`layout.json`）、道路の当たり判定メッシュ（`road_tiles.json`）、地図、場面ファイル、テクスチャ、共通の場面モデル（`src/shared/scenario.js` ＝ Web エディタと同じもの）。
4. `blender -b --factory-startup --python tools/build_impressionist.py` → ブラウザが使う独立した印象派モデルを `data/models/impressionist/` に生成します。元の glb は残し、町家・蔵・木・街灯・信号機・5 種類の車は新たな形を作ります。ほかのモデルは元の glb の座標を読み、頂点カラーと立体の筆触を加えた新しいメッシュにします。この手順は Unity の生成スクリプトに依存しません。Mac の標準インストールでは `blender` の代わりに `/Applications/Blender.app/Contents/MacOS/Blender` を使えます。

環境・場面・地図を変えたら 1〜4 をやり直します。`npm test` でロジックとデータ、印象派モデルの頂点カラー、道路・車の輪郭（元のモデルから 8 mm 以内）、街灯底面の向き、閉じたメッシュ、信号機の配置と向きを確認できます。`manifest.json` はモデルごとの三角形数・立体筆触数・ファイルサイズを記録します。一部だけ作り直す場合は末尾に `-- --only HK_Machiya_A HK_Tree_Sakura` のように付けます。

通常の生成は高精細版と `.lod.glb` を同時に更新します。既存の高精細モデルから遠景用の筆触だけを間引く場合は `-- --lod-only` を使います。これなら保存済みの形や色を再生成しません。LOD の輪郭、全 1260 配置のバッチ行列、VR パネルの不要な更新、影のキャッシュと動的更新も `npm test` で確認します。

画風確認用の固定視点：`http://127.0.0.1:8770/?view=street`（街並み）、`?view=architecture`（町家）、`?view=foliage`（樹木）、`?view=bridge`（橋）。`&finish=off` を付けると、材質の追加仕上げを外してモデル自体の色と筆触を確認できます。小物の近景は `?view=lamp`（街灯の仰視）、`?view=lamp-top`（上面）、`?view=signals`（信号正面）、`?view=signals-back`（背面）、`?view=vehicles`（車）、`?view=vehicles-back`（後方）です。小熊の近景は `?view=animal`、自転車は `?view=bicycle`、乗車姿勢は `?view=cyclist` です。`?view=ride` は場面 07 の体験を開始します。動作確認用の記録を実際のリプレイ操作で再生する場合は `?view=replay`（歩行）、`?view=replay-bicycle`（自転車）です（確認用の記録で、実験参加者のデータではありません）。通常の体験は `/` で始めます。

`-- --save-library` を付けて生成すると、9 つの小物を並べた編集用 `data/models/impressionist/abstract-props.blend` も保存します。造形方針は `docs/abstract-props.md` にあります。

## 作り

| ファイル | 内容 |
| --- | --- |
| `src/app.js` | 画面の流れ（タイトル → 体験 → 接触 → リプレイ → 結果）、キーとボタン |
| `src/touch-controls.js` | スマートフォン・タブレット：移動スティックとドラッグでの見回し（体験中だけ表示） |
| `src/world.js`, `src/environment-instances.js` | 街：資産ごとに部品を 1 つの形状へまとめ、共有の顔料マテリアルで InstancedMesh 描画。配置ごとの視錐台・影範囲の選別、遠景 LOD（ヒステリシス付き）、大きな資産の区画分割。元の配置・頂点カラーを維持し、空・光・影・霧を構成 |
| `src/resolution.js` | パソコンの動的解像度：約 50 FPS を下回ると段階的に下げ、余裕があれば戻す（行き来しないよう直前の段階を一定時間上限にする） |
| `src/signals.js`, `src/signal-layout.js` | 新しい信号機を元の設置行列で配置。実寸の模型に元の箱のスケールを二重に掛けない |
| `tools/abstract_props.py` | 封じた街灯・信号機・車体の新しい造形。面取り、色面、車輪の空間、車窓、厚い灯盤 |
| `src/style.js`, `src/paint-texture.js` | 画風：キャッシュした冷暖色の絵の具と細い筆の毛、拡散材質、街全体で共有する顔料表マテリアル（`PigmentPalette`）、キャッシュした影、描いた空。全画面の後処理はなし |
| `tools/build_impressionist.py` | Blender による印象派モデルの生成。町家の曲面屋根・壁面、樹冠の枝葉、立体の筆触、頂点カラー、生成結果の manifest |
| `src/traffic.js` | 車の出現と動き（Unity 座標）：8 m/s² で巡航速度まで加速、トリガー、繰り返し、停止、接触判定 |
| `src/player.js` | 体験者：マウス＋キー／タッチ、透明な壁、地面の高さ、接触後の倒れる視点。速さは Quest 版と同じ約 2.4 m/s |
| `src/ground.js` | 地面の高さ：Unity の道路の当たり判定（車道 0.01・歩道 0.41・坂）から |
| `src/analysis.js` | 記録（20 Hz・12 秒）と評価：車の方を見ていた時間、左右の確認（Unity と同じ角度と文章） |
| `src/replay.js` | リプレイ（描画専用のコピー） |
| `src/replay-animal.js`, `src/crash.js` | リプレイ用の小熊（関節のある手足、身長と体重で体つき、手足を目標点へ伸ばす IK）と、接触の種類ごとの倒れ方 |
| `src/bicycle.js`, `src/replay-cyclist.js` | 色面を持つ自転車、距離に同期する車輪とペダル、グリップとペダルに手足を合わせる乗車姿勢（人と自転車は別々に倒れる）。体験中の一人称の手足にも使う |
| `src/performance.js` | `benchmark=1` の時だけフレーム時間、描画回数・三角形数、更新時間を集計し、FPS 要素の `data-benchmark` に JSON を保存 |

座標：Unity（左手系）を three.js（右手系）に移すとき x を反転し、向き（yaw）の符号を反転します。モデルも同じ反転で書き出されるので一致します（`src/coords.js`）。シミュレーションはすべて Unity 座標で行い、描画のときだけ変換します。

## Unity 版との違い

- 組み込み 06〜08 のコードだけにある動き（速度超過で止まらない、側面衝突）、信号の切り替わり、前の車への追従はありません（場面ファイルにない動きは再現しません）。信号は表示だけです（Unity と同じく赤が見る人の左側にあり、日本の実際の信号（赤が右）とは逆です）。
- 車は Unity のセダン（他社のモデルで再配布できない）の代わりに、同じ大きさの日本のセダンを使います。セダン・軽自動車・トラックは同じ寸法を保ちながら、抽象絵画の色面と体積を元に車体・車窓・車輪を作り直しています。
- CSV は書き出しません。音、雨・夜の設定はまだありません。
- 画面で見るのと Unity 版の VR で体験するのは別の刺激です。実験のデータとまぜないでください。
