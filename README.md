# Hikone Traffic Simulator（彦根交通安全シミュレーター）

[VRLearn](https://github.com/LinQisan/VRLearn)（歩行者向け交通安全 VR）のブラウザ版です。彦根・京橋の街で、10 の事故場面と自作の場面（JSON）をパソコンとスマートフォンで体験できます。VR は Unity 版を使ってください。

**すぐ試す：https://linqisan.github.io/hikone-traffic-sim/**

手元で動かす（Node.js が必要）：

```bash
node serve.mjs                 # http://127.0.0.1:8770/
node serve.mjs --host 0.0.0.0  # 同じ LAN のスマートフォンから http://<PC の IP>:8770/
```

## 操作

| | パソコン | スマートフォン・タブレット |
| --- | --- | --- |
| 移動 | W A S D・矢印 | 左下のスティック |
| 見回す | クリックしてマウス（Esc で解除）・Q / E | 画面をドラッグ |
| 自転車 | W こぐ・S ブレーキ（止まって押すと後ろへ）・A D ハンドル | スティック |
| やり直し | R | 「やり直し」 |
| メニューへ（いつでも） | M・「メニュー」 | 「メニュー」 |
| リプレイ | 俯瞰 / 運転者（V）・もう一度（B）・結果へ | 画面のボタン |

キーボードだけでも操作でき、スクリーンリーダーと「視差効果を減らす」設定にも対応しています。メニューの身長は目の高さと小熊の背丈に、体重は小熊の体つきに反映されます。

## 体験の流れ

場面を歩く・自転車で走る → 車と接触すると視点が体と一緒に倒れる → リプレイ（俯瞰、または事故車の運転席から） → 結果。確かめずに進むと事故車とぶつかり、止まって確かめれば車が通りすぎてから安全に渡れます。ゴールに着くと左右の確認の結果が出ます。

## シナリオエディタ

タイトル画面の「✎ シナリオエディタ」、または **https://linqisan.github.io/hikone-traffic-sim/editor/** から開きます。

1. 左の一覧から場面を開くか「＋ 新規」（ひな形はこのブラウザ版の 10 場面。走行経路は体験と共通で、別の id で保存されます）
2. 地図上で出発点・ゴール・トリガーをドラッグ（□ で大きさ、○ で向き）
3. 「✎ 車を描く」でクリックして点を置き、Enter で完了。右の「車」で速さや事故車を決める
4. 下の ▶ で動きを確かめ、チェックが OK なら「▶ ブラウザで試す」→「保存」

保存先：GitHub Pages や別の端末ではこのブラウザの中（「⇩ JSON」で書き出し）。この PC で `node serve.mjs` を動かし、隣に VRLearn があるときは `VRLearn/Scenarios/` に保存し、「▶ Unityで試す」「⇪ Questに送る」（USB / ワイヤレス adb、Quest はタイトルの「カスタム」→「読み直す」）も使えます。

## Unity 版との違い

- 実験ではありません。データは書き出さず、Unity 版の実験とはまぜないでください。
- 事故場面の車のタイミングはブラウザ用に作り直しています。信号は切り替わらず、音・雨・夜はありません。
- 街なかの歩道面は車道と同じ高さで、縁石は 15 cm、敷地は別の高さです。城への道は地形に沿います。
