# Hikone Traffic Simulator（彦根交通安全シミュレーター）

[VRLearn](https://github.com/LinQisan/VRLearn)（歩行者向け交通安全 VR）のブラウザ版です。彦根・京橋の街を自由に歩く・自転車で走る「自由探索」と、10 の事故場面・自作の場面（JSON）の練習を、パソコンとスマートフォンで体験できます。VR は Unity 版を使ってください。

**すぐ試す：https://linqisan.github.io/hikone-traffic-sim/**

手元で動かす（Node.js 22.19 以降の 22 系、または 24 以降が必要）：

```bash
npm ci
npm run dev                     # http://127.0.0.1:8770/
npm run dev -- --host 0.0.0.0   # 同じ LAN のスマートフォンから http://<PC の IP>:8770/
```

モデルの圧縮配信ファイルは起動・ビルド時に自動生成されます。

公開用ファイルは `npm run build` で `dist/` に生成し、`npm run preview` で確認できます。GitHub Pages の公開元を **GitHub Actions** に設定すると、main への push 時にビルド結果を公開します。`node serve.mjs` も Vite を起動する互換入口として使えます。

## 開発・ビルド

UI は React、交通ロジックとエンジンの制御は TypeScript、描画とプログラムによる模型制作はネイティブ Three.js です。従来の場面、速度・信号設定、入力、リプレイ、保存形式を維持しています。

```bash
npm install                     # ロックファイル通りの再現には npm ci
npm run dev                     # 開発、エディタ API、HMR
npm run typecheck               # strict TypeScript
npm test                        # 同じ交通ロジックの Node テスト
npm run check                   # 型・文書・全テスト・本番ビルド
npm run build                   # dist/ を生成
npm run preview                 # dist/ をローカルで確認
```

`dist/` を静的ホスティングに配置できます。Python や Node.js の本番サーバーは不要です。相対 URL のため GitHub Pages の `/hikone-traffic-sim/` でも動作します。`main` への push は公開操作です。ブラウザ保存は静的公開でも使えます。Unity/Quest への送信には、従来どおりこの PC 上の開発サーバーと対応する Unity プロジェクトが必要です。

```text
src/app/                 React の起動とエンジンのマウント
src/components/          メニュー・HUD・結果・エディタの React UI
src/editor/              地図操作・編集コマンド・保存 API
src/three/               描画・カメラ・入力・模型・材質・エンジン
src/simulation/          交通・信号・接触・事故・記録の独立ロジック
src/world/               場面データの解決と既存の配置生成器
src/data/                場面の読み込みと検証
src/state/、src/hooks/    低頻度の UI 通知
src/types/、src/export/   データ型と GLB/JSON の交換境界
```

[移行前後の機能表・実測・検証範囲](docs/react-typescript-migration.md) と [設計理由](RATIONALE.md) を参照してください。既存の模型・材質・カメラの JavaScript はそのまま利用し、交通計算とアプリ制御を strict TypeScript で検査します。R3F は使っていません。

Unity 用の交換 API は `vrlearn.exportScene()`（JSON の配置と全イベント）と `vrlearn.exportAsset('WEB_Sedan', 'high')`（独立した GLB の ArrayBuffer）です。後者は呼び出したときだけエクスポーターを読み込み、表示中の模型を変更しません。GLB は形状・頂点色・対応材質、JSON は座標・経路・信号や行動の設定を担当します。ブラシのカスタムシェーダーと交通行動は Unity 側で実装する必要があります。詳細は [交換データと制約](docs/react-typescript-migration.md#unity-exchange) にあります。

## 操作

| | パソコン | スマートフォン・タブレット |
| --- | --- | --- |
| 移動 | W A S D・矢印 | 左下のスティック |
| 見回す | クリックしてマウス（Esc で解除）・Q / E | 画面をドラッグ |
| 自転車 | W こぐ・S ブレーキ（止まって押すと後ろへ）・A D ハンドル | スティック |
| やり直し（練習） | R | 「やり直し」 |
| メニューへ（いつでも） | M・「メニュー」（自由探索では記録の画面を経由） | 「メニュー」 |
| リプレイ | 俯瞰 / 運転者（V）・もう一度（B）・結果へ | 画面のボタン |

キーボードだけでも操作でき、スクリーンリーダーと「視差効果を減らす」設定にも対応しています。タイトルの「あなたの体格」で身長・体重を変えられます（＋／− ボタンか直接入力）。身長は目の高さと小熊の背丈に、体重は小熊の体つきに反映されます。

## 自由探索

タイトルで「歩行」か「自転車」を選び、「探索を始める」を押します。京橋の交差点から国道沿いの駐車場までの通りに、東西・南北の車の流れがずっと走り続けます。10 の事故場面は、あなたが決まった場所を決まった向きで通ったとき（例：交差点の横断歩道を北へ渡り始める、トラックのあいだから道路へ出る、駐車場の出入口の前を自転車で通る、道路の右側を自転車で走る）に起こることがあります。起こるかどうかは抽選で、赤での進入や確認不足などの危険な行動のあとは起こりやすくなります。場面の車は、あなたから見えない遠くの地点で車の流れに加わり、あなたに向かって走るのではなく、それぞれの道を信号と見通しに従って走ります。

- 場面が無事に終わると、上に短い振り返り（無事・車が減速した・ヒヤリ）が出ます。
- 車と接触すると、リプレイと結果のあと「探索を続ける」で近くの歩道から再開できます。
- M（「メニュー」）で探索の記録（時間・距離・出会った場面・交通確認・接触とそのリプレイ）を見られます。ここから続ける、記録を JSON ファイルで保存する、タイトルへ戻るを選べます。
- 記録はブラウザのタブの中だけにあり、どこにも送信されません。タブを閉じると消えます。

## 体験の流れ（場面の練習）

自作の場面はタイトルの「カスタム場面（JSON）を開く」から選びます。読み込み中・完了・エラーはその下に表示されます。エラーでも直前の選択は残ります。内容や接続を直して同じファイルを選び直せます。

場面を歩く・自転車で走る → 車と接触すると視点が体と一緒に倒れる → リプレイ（俯瞰、または事故車の運転席から） → 結果。車は体験者の位置に合わせて出発せず、それぞれの運転者が信号・車間・見通しに応じて走ります。反応時間や制動力は車ごとに異なり、接触するかどうかは実際の動きで変わります。ゴールに着くと左右の確認の結果が出ます。

京橋の信号は歩車分離式で切り替わります。歩行者信号は全方向で同時に青・青点滅・赤となり、歩行者の青・青点滅中は車の信号がすべて赤になります。通常の車は赤信号で停止線に止まりますが、信号無視・速度超過・譲らない運転者も現れます。ただし、見通しや反応・制動距離によっては急な飛び出しに間に合いません。体験では、赤での進入・双方向の確認不足・自転車の逆方向走行によって、まだ判断していない車の危険運転の抽選率が上がります。標準は通常時 3%、危険行動時は最大 60%（現実の事故率ではありません）。守っていても危険な車の可能性は残るので、青でも左右と車の停止を確かめてください。信号の秒数は体験用の設定で、現地の正確な配時を再現したものではありません。

## シナリオエディタ

タイトル画面の「✎ シナリオエディタ」、または **https://linqisan.github.io/hikone-traffic-sim/editor/** から開きます。

1. 左の一覧から場面を開くか「＋ 新規」（ひな形はこのブラウザ版の 10 場面。走行経路は体験と共通で、別の id で保存されます）
2. 地図上で出発点・ゴール・トリガーをドラッグ（□ で大きさ、○ で向き）
3. 「✎ 車を描く」でクリックして点を置き、Enter で完了。右の「車」で上限速度・注目車・運転行動（抽選・通常・信号無視・速度超過・譲らない）・反応時間や制動力を決める
4. 「場面」で危険運転の抽選率や道路環境（可視距離・グリップ）を指定できます。下の ▶ で動きを確かめ、チェックが OK なら「▶ ブラウザで試す」→「保存」

地図の場所を伝えるには「⌖ 座標」（P）を選び、地点をクリックして、右に開く座標パネルの「コピー」を押します。X は右向き、Z は上向きに増え、単位は m（シーン・場面 JSON と同じ座標）です。グリッドと目盛りは拡大率に合わせて変わり、「表示」から切り替えられます。X・Z を入力して「表示」を押すと、その場所へ移動できます。座標モードで地図にフォーカスして Enter を押すと中央を指定します。地点の指定は場面の内容を変更しません。`editor/?x=47.2&z=16.1` のようなリンクでも地点を開けます。

地図はゲームの模型から作った俯瞰図です。「▦ 地図全体」（G）で彦根城・堀・滋賀大学まで表示し、「⤢ 場面全体」（F）で編集中の場面に戻れます。京橋周辺は高精細図を重ねています。「表示」の「通行不可（堀など）」で通れない範囲を重ねられます。地図全体を開くリンクは `editor/?overview=1` です。

保存先：GitHub Pages や別の端末ではこのブラウザの中（「⇩ JSON」で書き出し）。この PC で `npm run dev` を動かし、隣に VRLearn があるときは `VRLearn/Scenarios/` に保存し、「▶ Unityで試す」「⇪ Questに送る」（USB / ワイヤレス adb、Quest はタイトルの「カスタム」→「読み直す」）も使えます。

## Unity 版との違い

- 実験ではありません。自由探索の記録は手元で保存するときだけファイルになり、送信されません。Unity 版の実験データとはまぜないでください。
- 車ごとの運転者行動はブラウザ独自の簡易モデルです。下のエディタ再生は同じ制御を使いますが、体験者の移動や街の遮蔽を含みません。音・雨・夜はありません。
- 街なかの歩道面は車道と同じ高さで、縁石は 15 cm、敷地は別の高さです。城への道は地形に沿います。
