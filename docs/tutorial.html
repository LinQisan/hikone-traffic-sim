快速上手

快速上手

安装、启动、玩一次内置场景，并了解检查和发布命令。

准备

需要 Node.js 22.19 以上或 24 以上，以及本仓库的副本。以下命令都在仓库根目录执行。

仓库根目录
npm ci

启动

仓库根目录
npm run dev

打开 http://127.0.0.1:8770/。同一个服务还提供 /editor/ 和 /docs/。

要在手机上访问，改用 npm run dev -- --host 0.0.0.0，再用电脑的局域网地址打开。

编辑器的两种保存方式

如果仓库旁边有 Unity 项目 ../VRLearn，开发服务会启用本地 API，场景保存到 Unity 项目中；否则编辑器把场景存在浏览器里。

玩一次

  1. 选择场景。在标题菜单的“横断歩道・交差点”分组中选 01，按 練習を始める。

  2. 走出去。不看左右，按住 W 直接往前走。车辆接触后会进入事故回放。

  3. 看结果。回放结束后按 結果へ進む，再按 タイトルへ 回到标题。

  4. 换个方式。再玩一次，在路缘停下左右确认，等车过去再走，应该能安全到达终点。

标题菜单左侧可以设置身高体重（影响视点高度），也可以直接开始自由探索。

改完之后检查

按改动范围选择最小的检查。常用的三个命令：

命令用途
node --test test/<文件>.test.mjs只跑受影响的测试文件。
npm test完整回归，包括事件检查。
npm run check类型检查、文档生成核对、完整回归、生产构建。CI 用的也是它。

哪类改动需要哪些检查，见常见任务：选择检查。

构建与发布

仓库根目录
npm run build
npm run preview

npm run build 生成 dist/，所有链接都是相对路径，可以部署在任意子目录。

推送 main 即发布

推送到 main 后，GitHub Actions 先运行 npm run check，通过后把 dist/ 发布到 GitHub Pages。
