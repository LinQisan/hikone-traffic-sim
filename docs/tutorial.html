教程

在本机跑通一次练习

大约十分钟。你会启动开发服务，玩一次内置场景 builtin-01，看完事故回放和结果，再回到标题页——确认整条流程在你的机器上是通的。

准备工作

你需要桌面版 Chrome、Node.js（22.19 及以上或 24 及以上），以及本仓库的本地副本。下文所有命令都在仓库根目录执行。

我们要玩的是内置场景 builtin-01。故意不观察直接往前走，就会触发模拟事故，正好能把练习、回放和结果三个画面都走一遍。

练习与回放

按顺序完成以下七步。

  1. 启动本地服务。在终端运行以下命令。

    仓库根目录
    npm ci
npm run dev

    看到 Local: http://127.0.0.1:8770/ 就说明启动成功，保持这个终端开着。如果该地址上已有服务在运行，直接进入下一步。

  2. 打开标题页。在 Chrome 中打开 http://127.0.0.1:8770/。

    加载完成后会看到标题菜单：左侧是体格设置和自由探索，右侧是场景列表和 練習を始める 按钮。

  3. 选择事件。在 横断歩道・交差点 分组中选择 01 手前の車線を右から来る車。

    选中的卡片会变成浅蓝色。

  4. 开始练习。选择 練習を始める。

    画面切换到京桥街区，左上角显示当前场景名称。

  5. 触发事故演示。保持初始朝向，按住 W 向前走。

    与车辆接触后，画面先播放倒地过程，随后进入 事故のリプレイ / Accident replay。这时可以松开 W。

  6. 查看结果。等待回放停在最后一帧。

    按钮变成 結果へ進む / Next，点击它。结果页会显示 事故が起きました / What happened 以及这次的观察反馈。

  7. 回到标题页。选择 タイトルへ / Title (Enter)。

    标题菜单重新出现。到这里，你已经在本机完整跑通了一次练习与回放。
