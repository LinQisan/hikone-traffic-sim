# 路灯、信号机与车辆的抽象造型

这一轮先提炼体块再建模。把物体看成有重量的色面：暖黄灯体、蓝紫金属轮廓、车身的大曲面、深蓝车窗和圆形车轮。减少密集条纹和零件，保留让人识别物体、判断朝向与交通状态的轮廓。色面直接写进几何顶点，关闭材质修饰也能成立。

- **路灯**：略微收腰的八边灯体，奶油黄的四周和底面，深蓝紫的封闭底托，厚实的八角斜顶。灯杆与横臂用封口的锥形管。仰视时看到完整封闭的底托，没有缺面破口；暖色灯体本身也有真实底盖，侧看有明确的厚度。
- **红绿灯**：倒角的深色封闭壳体，红、黄、绿三个有厚度的圆盘与闭合遮光眉。行人灯用红色站立、绿色迈步的简洁人形。背面、底面、遮光眉与立杆都有实体厚度。保留原场景的红黄绿顺序、位置和实际灯盘的负 Z 朝向；灯色不参与装饰性改色。
- **车辆**：轿车用低矮的弧线楔体，轻型车用较高或较短的弧顶体块，货车用独立的倒角驾驶室和浅灰货箱。车轮是封闭的圆形厚盘；轮拱真正让出空间。车窗贴合收窄的车顶，采用少量深蓝色面，车底与前后端盖封闭。去掉机械式密集门缝与货箱细肋。

生成代码位于 `tools/abstract_props.py`，由 `tools/build_impressionist.py` 调用。三个新信号机资产放在 `data/models/impressionist/`，用 `data/signals.json` 的安装矩阵定位；车辆继续使用现有模型名、车色机制与碰撞尺寸。

验证包括：灯体与信号壳体的网格闭合、底面法线朝外、车辆车身与车底闭合、车辆外边界对齐，以及浏览器中仰视、正面、背面和车辆近景。

编辑工程：`data/models/impressionist/abstract-props.blend`。运行 `blender -b --factory-startup --python tools/build_impressionist.py -- --save-library` 可以重建全部资产与工程；`--only` 可以指定这次需要更新的模型。

浏览器近景：`?view=lamp&finish=off`、`?view=lamp-top`、`?view=signals&finish=off`、`?view=signals-back`、`?view=vehicles&finish=off`、`?view=vehicles-back`。这些检查视点使用实际运行的 GLB，不修改场景或交通规则。
