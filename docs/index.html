彦根京桥交通安全练习工具的开发资料。第一次接触项目，从教程开始；要完成具体任务，看操作指南；查字段和接口，翻参考；想知道为什么这样设计，读设计解释。

从哪里开始

四篇文档各管一件事，按你现在要做的事挑一篇。

教程 →在本机跑通一次练习启动开发服务，玩一个内置场景，看完事故回放和结果。 操作指南 →修改一个内置事件改事件源文件、重新生成数据，再检查路线和教学行为。 参考 →运行时与数据接口源码职责、状态机、场景字段、坐标、信号相位和本地 API。 设计解释 →交通逻辑为何与画面分离逻辑、渲染、碰撞、回放和编辑器之间的依赖与取舍。

项目是什么

Hikone Traffic Simulator 是一个在浏览器里运行的交通安全练习工具。舞台是彦根京桥一带：参与者可以步行或骑自行车自由探索，也可以单独练习 10 个内置事故场景或自定义场景；每次练习结束后有事故回放和观察反馈。项目不收集任何实验数据。

技术栈是 React + strict TypeScript + 原生 Three.js + Vite。运行 npm ci 安装依赖，npm run dev 启动开发服务（同时提供编辑器 API），npm run build 生成可部署到任意子目录的 dist/。街区模型在运行时由 models/ 中的建模指令生成（入口为 src/three/assets/models.js），不加载 GLB。

项目最初沿用 VRLearn 的地图和场景格式，如今事件、道路修正和编辑器模板都由本仓库维护，不要求与 VRLearn 保持一致。网页面向桌面和触屏设备，VR 体验由 Unity 项目提供。

仓库里的其他文档

每条事实只记录在一个地方。下面这些文件与本站互补：

README.md
面向使用者的日文说明：如何启动、如何操作、如何使用编辑器。
AGENTS.md
开发规则（英文）：数据来源、约束，以及每类改动需要跑哪些检查。
RATIONALE.md
设计理由（英文）：事件模型、驾驶者行为、回放等为何如此设计。
DESIGN.md
界面设计规范（英文）：颜色、字号、组件与无障碍要求。
docs/art-and-performance.md
模型生成、地图依据与性能测量记录（英文）。
docs/event-review.md
内置事件的逐一检查记录（英文）。

这套文档如何维护

docs/ 路由对应 docs/index.html。每篇文档都是独立的静态 HTML，共用 docs/developer.css 与 docs/developer.js，不加载 Three.js、街区模型或编辑器 API，打开很快。

脚本只做渐进增强：窄屏时折叠目录、高亮当前章节、为代码块加复制按钮。关闭 JavaScript 后正文和锚点照常可用。站内链接一律使用相对路径，以便部署在 GitHub Pages 的仓库子路径下。

参考页中的场景默认值、信号相位和录制常量由 tools/build_developer_reference.mjs 直接从源码生成，不要手改。命令见文档维护参考。
