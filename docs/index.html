Hikone 开发文档

彦根京桥交通安全练习工具的开发文档：项目由哪些部分组成、如何协作、数据从哪里来、改动时如何验证。

这是什么

Hikone Traffic Simulator 是在浏览器中运行的交通安全练习工具，场景是彦根京桥一带。参与者可以步行或骑自行车：

  • 自由探索：在一条连续的街道上活动，10 个事故场景会在合适的地点作为“遭遇”出现。
  • 场景练习：单独练习一个内置场景或自制场景，结束后看事故回放和观察反馈。
  • 场景编辑器：在地图上布置起点、终点和车辆路线，保存后直接试玩。

项目不收集任何数据，探索记录只留在浏览器标签页里。

整体结构

三条约定贯穿整个项目：

  • 逻辑与画面分离。车辆、信号、碰撞只用地图坐标和场景时间计算，画面怎么剔除、相机看哪里都不影响结果。
  • React 不管每一帧。React 只负责普通界面；每帧变化的车辆、人物和相机由引擎直接更新。
  • 生成的数据不手改。data/ 由脚本从 events/、模型和地图生成，改源头再重新生成。

目录一览

src/app/、src/components/
React 界面：模拟器和编辑器的页面组件。
src/state/、src/hooks/
界面状态快照与订阅。
src/three/
Three.js 引擎、场景、实体、相机、材质、模型构建与输入。
src/simulation/
与画面无关的模拟逻辑：场景格式、交通、信号、遭遇、碰撞、录制与分析。
src/world/
自由探索配置的解析，以及街区布局生成器。
src/editor/
编辑器控制器、浏览器存储和地图坐标。
src/export/、src/types/
GLB/JSON 导出接口；全项目共用的类型。
events/、world/
手写的源数据：内置事件和自由探索配置。
models/、data/
模型构建指令；由工具生成的场景、地图与碰撞数据。
server/、tools/、test/
本地编辑器 API；生成与检查工具；回归测试。

怎么读

快速上手 →在本机跑起来安装、启动、玩一次、跑检查。 系统结构 →代码如何分层协作启动流程、帧循环、状态、两种模式和编辑器。 数据与资源 →数据从哪里来事件、模型、地图和碰撞的生成链，以及构建发布。 常见任务 →改什么、怎么验证改事件、车流、模型、界面，选择检查，发布。

字段、常量、接口和命令的完整列表在参考。设计理由见仓库中的 RATIONALE.md，界面规范见 DESIGN.md，开发规则见 AGENTS.md（均为英文）。
