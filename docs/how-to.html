常见任务

常见任务

修改事件、自由探索、模型和界面时的具体步骤，以及每类改动需要的检查。

修改内置事件

  1. 编辑 events/builtin-01.json（换成你要改的 ID）。字段见参考：场景格式。

  2. 重新生成模拟器和编辑器使用的副本，并查看差异。

    仓库根目录
    node tools/sync.mjs --events-only
git diff -- data/scenarios/ data/editor/

  3. 检查事件目的：谨慎通过能到达终点，车辆出现时被遮挡或在远处。

    仓库根目录
    node tools/check_events.mjs builtin-01

  4. 改了路线时，再检查车辆是否留在道路上。

    仓库根目录
    node tools/check_routes.mjs
node --test test/routes.test.mjs

  5. 在浏览器里分别“直接走”和“停下确认”各玩一次。

不要用编辑器保存来替代：编辑器只保证保留已支持的字段，而且不能覆盖内置模板。

调整自由探索

车流、遭遇区域、抽选概率、闯红灯应答都在 world/hikone.json。路线只能引用 events/ 中的路线或写明确的连接点。

仓库根目录
node --test test/world.test.mjs test/scenario-manager.test.mjs test/routes.test.mjs
node tools/check_red_crossings.mjs 20 walking

check_red_crossings.mjs 统计不看路闯红灯时的接触率，按被横穿道路的信号分组，用于调整危险程度。

修改模型或布局

  1. 修改程序化建模源（tools/*.py）或布局生成器（src/world/generators/）。

  2. 重新编译构建指令（需要 Blender），然后重建碰撞网格。

    仓库根目录
    blender -b --factory-startup --python tools/build_native_models.py
node tools/build_collision.mjs

  3. 检查模型和通行空间：所有起点和到终点的路都必须保持通畅。

    仓库根目录
    node --test test/art.test.mjs test/obstacles.test.mjs

改动影响绘制量时，打开 ?benchmark=1 在同一页面前后对比；目标是约 120 次绘制调用，不使用后期处理，移动物体不进太阳阴影。

修改界面

  • 模拟器界面在 src/components/，样式在 style.css；编辑器在 src/components/editor/ 和 editor/editor.css。
  • 颜色、字号和组件规则见 DESIGN.md，两份样式表的设计变量要保持一致。
  • 编辑器元素的 id 被 controller.ts 使用，可以改样式，不要改 id。
  • 保持无障碍：键盘可操作、44 px 触控目标、屏幕阅读器播报、减少动态效果、强制颜色模式。

改完在桌面（1440 × 900）和手机宽度（375 × 812）下各看一遍，确认控制台没有错误。

选择检查

只跑能覆盖改动的最小检查。规则来自 AGENTS.md：

改动需要的检查
文档、注释、格式核对内容和路径，git diff --check
样式、文案查看受影响的页面，确认键盘与触屏可达、控制台无错误
单个逻辑修复node --test test/<相关>.test.mjs，补一个回归测试
车辆与转向test/turning.test.mjs，按需加 logic / crash / bicycle
模型、布局、碰撞重新生成；test/art.test.mjs、test/obstacles.test.mjs
自由探索test/world.test.mjs、test/scenario-manager.test.mjs，车流改动加 routes
单个事件node tools/check_events.mjs <id> 并试玩
编辑器存储或服务editor-store / editor-server / editor-quest 测试
共享时序、接触、坐标、依赖或不确定npm run check，并试玩一个步行和一个骑车事件

提交与发布

提交前运行 git diff --check，在提交说明中写清改了什么、跑了哪些检查、哪些没有验证（例如没有真机测试）。

推送 main 会部署站点

推送前完成适用的检查。CI 会再运行一次 npm run check，失败则不发布。
