这些文件都会被重新生成。要改内容，改 events/、world/、models/ 或生成器，再运行对应命令。

坐标与高度

所有数据都用导入地图的坐标，单位为米：在编辑器地图上 X 向右、Z 向上，yaw 从 +Z 起顺时针计角度。只有 src/three/scene/coords.ts 负责转换到 Three.js（X 取反）。

高度约定：车道和城区人行道 0.01 m，独立路缘顶 0.16 m，城区地块 0.15 m，城堡坡道跟随地形。改高度要改生成几何，不要在渲染时加偏移。

模型如何到达浏览器

models/ 中每个资产有高精度 NAME.json 和低精度 NAME.lod.json 两份构建指令，不是网格文件。Vite 启动或构建时，pack_models.mjs 把它们压缩到 models/packed/（可随时删除），并写出清单 models/runtime.json。

浏览器用有限数量的 Worker 执行这些指令，生成原生 Three.js 几何体；触屏设备只用一个 Worker，以控制内存峰值。旧的 GLB 文件只作为离线对照样本，运行时不加载。

构建与部署

  1. 检查类型 → 文档生成核对 → 完整测试 → 生产构建npm run check
  2. 打包Vite 多页构建；复制 data/、models/、world/、*.mddist/
  3. 发布推送 main 后由 GitHub Actions 部署GitHub Pages

站点部署在仓库子路径下，所以页面中的链接和数据地址都用相对路径。工具、测试和旧 GLB 不进入 dist/。
